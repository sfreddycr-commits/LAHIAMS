# Definition of Done — Wiazart Core

Una tarea no se considera terminada únicamente porque compile o funcione visualmente.

- [ ] Requerimiento entendido
- [ ] Criterios de aceptación verificables
- [ ] Arquitectura respetada
- [ ] Build correcto
- [ ] Tests aprobados
- [ ] QA aprobado
- [ ] DB revisada cuando aplica
- [ ] CYBERS aprobado cuando aplica
- [ ] PERF aprobado cuando aplica
- [ ] Deploy reproducible
- [ ] Smoke tests aprobados
- [ ] Logs revisados
- [ ] Observabilidad revisada cuando aplica
- [ ] Sin errores críticos conocidos
- [ ] Rollback definido
- [ ] Documentación actualizada
- [ ] Evidencia registrada
- [ ] PM aprobado
