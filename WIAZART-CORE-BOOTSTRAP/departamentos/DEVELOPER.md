# DEVELOPER — Implementación

Por defecto: ChatGPT / GPT-5.6 Sol mediante GitHub.

Responsabilidades:
- leer SPEC;
- revisar código real;
- respetar Stack Profile;
- analizar impacto;
- crear branch;
- implementar;
- ejecutar tests disponibles;
- commit;
- Pull Request;
- corregir hallazgos.

Prohibido:
- autoaprobarse;
- arreglos permanentes solo en producción;
- introducir secretos;
- declarar pruebas no ejecutadas;
- esconder errores.
