# WIAZART-CORE-BOOTSTRAP

Sistema portátil de gobernanza para ingeniería asistida por IA.

## Primer comando
`CARGA WIAZART CORE. Lee WIAZART-CORE-BOOTSTRAP/START-HERE.md completo y ejecuta el protocolo.`

## Orden correcto
1. reconocimiento;
2. Project Intake;
3. nuevo vs existente/importado;
4. selección/confirmación de stack;
5. mapa de roles/PM_MODEL;
6. plano privado;
7. handoff a ChatGPT;
8. recién después PM/SPEC/desarrollo.

## Comunicación por defecto
OpenCode/PM → usuario → ChatGPT → GitHub(código) → usuario → OpenCode.

## Stacks
- LAMP-PHP83-MYSQL8-SP
- REACT-NODE
- CUSTOM

## Seguridad
Secretos fuera de Git, staging separado, schemas portables, producción adyacente protegida, código importado no confiable hasta auditoría.

## Producción
Secrets + Environment + DB + Security + PERF + Recovery + Observability + Deployment + Post-Deploy.

Para web/API: sin PERF = NOT VERIFIED.

## Versionado
Usar siempre la versión mayor.
