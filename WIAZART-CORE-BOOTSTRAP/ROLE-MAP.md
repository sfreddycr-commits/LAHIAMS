# ROLE-MAP — Wiazart Core

## PO
Usuario / Product Owner.

## PM
Rol de Project Management.
Registrar `PM_MODEL`.
Puede ejecutarse dentro de OpenCode.

## DEVELOPER
Por defecto ChatGPT / GPT-5.6 Sol.
Trabaja principalmente sobre GitHub.

## OpenCode
Agente local con acceso al proyecto/VPS.
Puede hospedar PM y ejecutar QA/DEVOPS/SRE/PERF/CYBERS.

## Independencia
Quien implementa no se autoaprueba. La verificación debe basarse en evidencia.
